ERPNext Backup

A personal backup integration operated by Sergey Antohin. It uses rclone to upload ERPNext backup archives from the owner's server to the owner's Google Drive and retrieve them for restoration.

This application is for the owner's private use, not a public backup service. Google Drive authorization is requested only from the owner. The intended drive.file permission limits access to files created or explicitly authorized for this application.

No backup archives, OAuth credentials or tokens are published on this website.
