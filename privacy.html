ERPNext Backup Privacy Policy

Effective date: November 19, 2026.

Purpose and operator

ERPNext Backup is a private integration operated by Sergey Antohin to store and restore backups of the owner's ERPNext installation using rclone and Google Drive.

Data accessed and use

The integration uploads backup archives and accesses their contents and file metadata as necessary to list, verify, download, restore and manage backup copies. Archives may contain ERPNext database records, attachments and configuration. The intended Google Drive permission is drive.file, covering files created or explicitly authorized for this application.

Storage and sharing

Backup data is processed on the owner's server and stored in the owner's Google Drive. OAuth tokens and client credentials are retained in the owner's rclone configuration and are not intentionally published. Google processes data under its applicable terms and privacy policy. Backup data is not sold, used for advertising, or supplied to AI model training services by this integration. This public website contains no backup archives or OAuth credentials. GitHub hosts this website and may process visitor technical data under its own privacy statement.

Retention and deletion

The owner controls backup retention and can delete local and Google Drive copies. Revoking Google account access prevents further authorized access but does not automatically delete existing backups. Deletion of stored copies is managed separately.

Google API user data

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For questions or deletion requests, contact iamsergeyantohin@gmail.com.
